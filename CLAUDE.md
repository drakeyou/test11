# Перед работой прочитай HANDOFF.md

`HANDOFF.md` в корне — полное состояние проекта: карта репозитория, схема
данных, конфигурация с последствиями каждого параметра, решения и их причины,
внешние API, грабли, недоделанное и команды проверки. Прочитай его целиком
прежде чем что-либо менять: несколько мест выглядят странно и имеют причину,
записанную там (защиты детектора свипов, разделение `disciplines` и `labels`,
либеральная запись свипов с фильтром на стороне анализа).

`README.md` — как устроены сайты и протоколы gg.bet и Polymarket.

Жёсткие ограничения проекта:
- Только чтение. Ни ключей, ни подписи ордеров, ни выставления заявок.
- Не менять формат выходных файлов сборщика gg.bet.
- Собранные данные (`data/`, `*.csv`) в git не попадают и живут только на
  машине сбора.
